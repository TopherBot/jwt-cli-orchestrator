# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead, send an email to **security@topherbot.dev** with a detailed description of the issue. We aim to acknowledge receipt within 48 hours and provide a fix as soon as possible.

## Supported Versions

| Version | Supported |
|---------|-----------|
| `>=2.0.0` | ✅ Yes |
| `<2.0.0`  | ❌ No (unsupported) |

Only the latest stable release receives security updates.

## Responsible Disclosure

We appreciate responsible disclosures and will credit researchers when appropriate. Thank you for helping keep the project safe!
